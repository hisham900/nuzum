بالعربية

نُظم برنامج يعمل على أجهزة المحل. بيانات المحل (الأصناف والفواتير والعملاء وغيرها) تُحفظ في قاعدة بيانات على أجهزة المحل نفسه، ولا تُرسل إلى أي خادم لنا. ليس لدينا خادم يخزّن بيانات المحلات أو بيانات حسابات جوجل.

عند ربط حساب جوجل (اختياري)

يطلب البرنامج هذه الصلاحيات فقط:

  • drive.file: لإنشاء ملفات البرنامج في درايف صاحب المحل وقراءتها (مجلد «Nuzum Backups» للنسخ الاحتياطية، وملف «نُظم - تقارير» لتقارير الجوال). لا يرى البرنامج أي ملف آخر في الدرايف.
  • email و openid: لعرض الإيميل المربوط داخل البرنامج فقط.
  • صفحة تقارير الجوال تطلب spreadsheets.readonly لقراءة ملف التقارير الخاص بصاحب المحل وعرضه له فقط، وتعمل بحساب من يفتحها.

كيف نستعمل البيانات

  • تذهب النسخ الاحتياطية وملخصات التقارير مباشرة من جهاز المحل إلى حساب جوجل الخاص بصاحب المحل، ولا تمر بأي خادم لنا.
  • رمز الدخول (refresh token) يُحفظ مشفّراً على جهاز المحل فقط (Windows DPAPI). لا نحفظ أي كلمة مرور.
  • لا نبيع البيانات، ولا نستعملها للإعلانات، ولا نشاركها مع أي طرف، ولا يطّلع عليها أي شخص منا.

إلغاء الربط وحذف البيانات

يمكن إلغاء الربط في أي وقت من البرنامج (الإعدادات ← النسخ الاحتياطي ← «إلغاء الربط»)، أو من myaccount.google.com/permissions. الملفات التي أنشأها البرنامج تبقى في درايف صاحب المحل ويمكنه حذفها متى شاء.

English

Nuzum is a point-of-sale and accounting program that runs on the shop's own Windows computers. The shop's data (items, invoices, customers and so on) is stored in a database on those computers and is never sent to a server of ours. We do not operate any server that stores shop data or Google user data.

When a Google account is linked (optional)

Nuzum requests only these scopes:

  • https://www.googleapis.com/auth/drive.file: to create, read, update and delete only the files Nuzum creates in the shop owner's Google Drive (the "Nuzum Backups" folder with the daily backups, and the "Nuzum reports" spreadsheet for the phone reports). Nuzum cannot see any other file in the Drive.
  • email and openid: only to show which Google account is linked, inside the program.
  • The Nuzum phone reports page requests https://www.googleapis.com/auth/spreadsheets.readonly to read the shop owner's own reports spreadsheet and show it to that same person. It runs as the person who opens it, so nobody else can read a shop's reports.

How the data is used

  • Backups and report summaries go directly from the shop's computer to the shop owner's own Google account; they do not pass through any server of ours.
  • The OAuth refresh token is stored encrypted on the shop's computer only (Windows DPAPI). No passwords are stored.
  • We do not sell Google user data, do not use it for advertising, do not transfer it to third parties, and no person at Nuzum reads it.

Nuzum's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Unlinking and deletion

The account can be unlinked at any time in Nuzum (Settings → Backup → Unlink), or at myaccount.google.com/permissions. Files Nuzum created stay in the owner's Drive, and the owner can delete them at any time.
